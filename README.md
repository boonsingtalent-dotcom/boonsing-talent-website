# Boon Sing Talent Website

A Vite + React website prepared for deployment on Vercel.

## Local preview
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Upload this project to a GitHub repository.
2. Go to Vercel > Add New Project > Import the GitHub repository.
3. Framework Preset: Vite.
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. Deploy.
7. In Vercel, go to Project > Settings > Domains and add `boonsingtalent.com` and `www.boonsingtalent.com`.
8. In Namecheap DNS, point the domain to Vercel following Vercel's domain instructions.
